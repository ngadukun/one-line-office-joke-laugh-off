One original one-line office joke, printed by a tiny Python program — an
entry for make.fun's "One-Line Office Joke Laugh-Off" bounty ($3 in USDC).

The joke is about the most painfully true office ritual of all: the
reply-all chain that nobody can stop, not even the person asking everyone
to stop.

## Run it

```sh
python3 main.py
```

It prints exactly one line and nothing else:

```
Someone replied-all to say 'please stop replying-all,' and 47 people replied-all to agree.
```
